## 三、本轮 QA 抓到并已修复的真实缺陷

### 🐛 AB 对比：空请求静默变成付费运行（真实扣费）

- **现象**：`POST /api/tools/ab-compare` 传空 body 时不报错，返回 200 —— 而且
  **真的跑完了整套流程并扣了 $0.024**（embedding + GSB 各一次 LLM 调用）。
- **根因**：`_resolve_ab_group()` 里 `mode = request.form.get(...) or "db"`，
  缺参数时静默兜底成"数据库一键填充"，拉 20 条最新事件当对比素材。
- **影响面**：任何误发的请求都会烧钱——前端 bug、写错的 curl、失败重试，
  都会变成一次没人要的付费对比。
- **修复**：mode 必须显式声明（`db`/`text`/`image`），缺失或非法一律 400。
  前端一直显式发 `group_x_mode`，正常流程不受影响。
- **回归**：QA 用例升级为「空输入应 400 **且零花费**」，二次执行通过。

> 另有 1 项失败是我自己的断言写错了（`turnover` 键在 JSON 深处，被前 2000
> 字符截断误判），已改成按键名严格断言，不是产品缺陷。**如实记录，不美化。**

## 五、已知限制（非缺陷，明示口径）

这些是**刻意接受**的设计选择，已与 Lawrence 确认，不计入 bug：

1. **HTTP + 静态 token**（内部工具定位，仓库保持 private）；HTTPS 走 Cloudflare
   quick tunnel，隧道重启后子域名会变。
2. **单实例无高可用**；靠每周备份 + 本地副本兜底。
3. **切时区前的历史行时间戳仍是 UTC**（比北京时间早 8 小时），刻意不回填——
   回填会污染 72h 归并窗与新鲜度过滤的比较基准，随数据老化自然淘汰。
4. **6 个 blueprint 各自复制鉴权代码**：已知技术债，换取多 agent 并行开发时零
   耦合；等迭代放缓统一收口。
5. **X 通道受 credit 余额约束**：余额耗尽时 X 接口返回 402，pipeline 照常运行
   （其余 6 类信源不受影响），但当轮无 X 召回。

```bash
ssh manus-vm "cd ~/crypto-news-crawler && set -a && source config/.env && set +a && python3 scripts/qa_suite.py"
```

- 退出码 0 = 全绿；非 0 = 有失败，末尾打印失败明细，**不得交付**。

  不依赖当天数据内容，因此可以无脑重跑。
