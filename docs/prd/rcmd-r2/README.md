## 最终分公式

```
FinalScore = BaseScore × MarketWeight × Freshness × (1 + Bonus)
BaseScore  = 0.26·影响面 + 0.16·广度 + 0.16·时效 + 0.14·冲击力 + 0.10·热度 + 0.10·权威 + 0.08·质量
Bonus      = min(同向加成 + 反转加成 + 交易实体加成, cap)     同向与反转互斥
最后再过一层混排（配额 / 置顶）
```

## 四条最容易踩的坑（每一条我们都付出过线上代价）

1. **判断"这个百分数是什么"是语义问题，不是模式匹配。** 正则+词表补到第三轮就该停手换 LLM 字段。实测规则口径误判 60%，LLM 12/12。
2. **情绪门槛必须用 `event_tier`，不能用 `importance_score`。** 后者会被时效/热度/权威污染，782 条 D 档事件轻松过线，把 KOSPI 熔断当天的情绪稀释成"中性"。
3. **三个查询时倍率绝不写回 `importance_score`。** 那是"事件本身多重要"的口径，被去重、实验室、历史分析共同依赖。
4. **取数 SQL / 计算 / 请求解析 / 响应序列化 / 界面渲染是五个独立环节，漏哪一处都不报错。** 加一个因子必须五处一起改，并写端到端断言钉住。
