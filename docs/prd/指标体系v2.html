B9 指标体系 v2

早午日报 · 宏观新闻 · 相关新闻 —— 按「能否指导动作」分组，每组明确方向
取代 v1（乘法链 + 北极星 + 制衡）—— v1 太表面、太 fancy，指标间的公式关系是构造出来的。 v2：每个数字都能指导一个动作。效果归因走 AB 实验——所有指标支持按 AA / AB 实验分组查看，AA 验证分流无偏，AB 差值给因果结论。
① 召回与稳定生产东西够不够越高越好
② 先验质量上屏的对不对仅监控
③ 后验质量用户认不认越高越好
④ 工程管道通不通optional

01召回与稳定生产 越高越好

指标定义
召回量该点位候选池事件数
S/A 级召回量候选池中 S/A 级事件数
S/A 级展示量实际展示给用户的 S/A 级事件数
站外召回覆盖率 CNBC / WSJ 前 10 头条的覆盖率，分两层：
· 事件库覆盖 —— 库里有没有（抓取能力）
· TOP10 露出覆盖 —— 首屏有没有（排序能力）

02先验质量 仅监控 · 非越高越好

这些指标互相拉扯（权威性拉满→单一信源；时效拉满→挤掉重要慢新闻）， 是约束不是目标，落在合理区间即可。
指标定义
多样性TOP10 的去重事件数、标的数
权威性TOP10 中 A 级事件占比
质量分TOP10 平均打分、最低打分
时效性TOP10 中 8 小时窗口、24 小时窗口内的占比
实体占比TOP10 中含可交易实体（股/币）的占比

03后验质量 越高越好

指标定义
人均曝光量曝光 PV ÷ 曝光 UV
UCTR点击 UV ÷ 曝光 UV
CTR点击 PV ÷ 曝光 PV
浏览时长人均、次均
访问率浏览后 24h 内访问标的物资产界面
交易率 / 交易额浏览后 24h 内交易标的物、及成交额
归因：已有 AB 实验体系。AA 组验证分流与口径无偏； 访问率 / 交易率等效果结论以 AB 差值为准。

04相关新闻 专项 仅监控

指标定义
Sector 覆盖率至少 1 / 2 / 3 条新闻覆盖的 sector 数、占比
标的覆盖率至少 1 / 2 / 3 条覆盖的单标的数；top100 币/股占比
平均相关性打分—
最低相关性打分兜底线
低相关占比相关性打分 < 0.65 的条数占比
覆盖率分 ≥1 / ≥2 / ≥3 三档：≥1 看广度（有没有荒漠区），≥3 看厚度（撑不撑得起模块）。

06下钻维度 与 落地优先级

下钻维度（所有指标交叉查看）

  • 点位：早报 / 午报 / 宏观 / 相关新闻
  • 时间：过去 1 天 / 3 天 / 1 周 等
  • 是否首屏
  • 是否未 FTTT 用户
  • 实验分组：AA / AB

落地优先级

  • P0 召回 + 先验 —— 现有数据即可算
  • P1 后验（AA/AB 分组）—— 依赖埋点回流接入
  • P2 相关新闻专项 —— 随模块上线
开放问题： ① FTTT 以哪个字段判定；② 曝光口径（进视口即计 vs 停留时长，首屏/非首屏需同口径）； ③ 0.65 阈值仅相关新闻还是全点位统一。
