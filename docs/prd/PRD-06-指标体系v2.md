# PRD-06 · 指标体系 v2

> **框架**：Lawrence 2026-08-19 定稿。取代 v1（乘法链 + 北极星 + 制衡）——v1 太表面、
> 太 fancy，指标间的公式关系是构造出来的。
> **v2 原则**：按「能否指导动作」分组，每组明确方向（越高越好 / 仅监控）。
> **归因**：已有 AB 实验体系，所有指标支持按 **AA / AB 实验分组**查看，
> 效果类结论以 AB 差值为准。

---

## 一、【早午日报 / 宏观新闻 / 相关新闻】

### 1. 召回与稳定生产 —— 越高越好

| 指标 | 定义 |
|---|---|
| 召回量 | 该点位候选池事件数 |
| S/A 级召回量 | 候选池中 S/A 级事件数 |
| S/A 级展示量 | 实际展示给用户的 S/A 级事件数 |
| 站外召回覆盖率 | CNBC、WSJ 前 10 头条的覆盖率，**分两层**：① 事件库覆盖 ② TOP10 露出覆盖 |

### 2. 先验质量 —— 监控，非越高越好

| 指标 | 定义 |
|---|---|
| 多样性 | TOP10 的去重事件数、标的数 |
| 权威性 | TOP10 中 A 级事件占比 |
| 质量分 | TOP10 平均打分、最低打分 |
| 时效性 | TOP10 新闻中 8 小时窗口、24 小时窗口的占比 |
| 实体占比 | TOP10 新闻中含可交易实体（股/币）的占比 |

### 3. 后验质量 —— 越高越好

| 指标 | 定义 |
|---|---|
| 人均曝光量 | 曝光 PV ÷ 曝光 UV |
| 点击率 | **UCTR** = 点击 UV ÷ 曝光 UV；**CTR** = 点击 PV ÷ 曝光 PV |
| 浏览时长 | 人均、次均 |
| 访问率 | 浏览后 24 小时内访问标的物资产界面 |
| 交易率 / 交易额 | 浏览后 24 小时内交易标的物、及其成交额 |

> 效果归因走 **AB 实验**：AA 组验证分流与口径无偏，AB 差值给因果结论。

## 二、【相关新闻】专项 —— 监控，非越高越好

### 1. 覆盖率

| 指标 | 定义 |
|---|---|
| Sector 覆盖率 | 至少 1 条新闻覆盖的 sector 数、占比；至少 2 条……；至少 3 条…… |
| 标的覆盖率 | 至少 1 条新闻覆盖的单标的数、top100 币/股占比；至少 2 条……；至少 3 条…… |

### 2. 相关性

| 指标 | 定义 |
|---|---|
| 平均相关性打分 | — |
| 最低相关性打分 | — |
| **低相关占比** | 相关性打分 **< 0.65** 的条数占比 |

## 五、开放问题（落地前需确认）

1. **FTTT 判定字段**：以哪个字段/表判定"未 FTTT 用户"。
2. **曝光口径**：进视口即计，还是需停留时长；首屏与非首屏需同口径。
3. **相关性阈值 0.65 的适用范围**：仅相关新闻，还是全点位统一。
