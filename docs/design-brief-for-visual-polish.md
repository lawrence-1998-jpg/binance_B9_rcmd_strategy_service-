# 视觉优化任务说明（给设计工具/Claude Design 用）

> 用途：Lawrence 打算把这个网站的视觉走查交给专门的设计工具做优化。这份文档
> 描述现状、约束和期望范围，写于 2026-07-26。

## 这是什么网站

B9 推荐策略服务的内部工作台，给团队看新闻事件抓取/打分/推荐的全链路结果，
不是面向最终用户的 C 端产品。使用者是内部同事和少数外部对接方（工程师 +
非技术同事都有）。

## 页面结构

**导航形态**：两个页面都是**左侧固定侧边导航栏**（238px 宽），一级导航 + 二级
子导航两层；窄屏（≤1080px）自动变成汉堡抽屉 + 遮罩。侧边栏已按语义分成两组，
组标题为小号 mono 字：**「新闻策略数据服务」**（01 生成流程 / 02 数据展示 /
03 API 接入）和**「策略产品工作态」**（04 评测工具及其 3 个子项 / 05 策略实验室
及其 2 个子项），06 历史数据在分隔线之后单独放。这个两组划分是 Lawrence 定的
信息架构，视觉可以重做，**分组语义要保留**。

**`web/index.html`**（主页面，同页 tab 切换，不刷新）：
- 01 生成流程 — 展示数据抓取→打分→入库的 pipeline 说明
- 02 数据展示 — 事件列表，含板块标签、市值标签、真实性校验状态、X 原帖信息
- 03 API接入 — 面向工程师的接口文档
- 04 评测工具（侧边栏里带 3 个二级子项）— Duplicate Tester / LLM评测室 / AB对比
- 05 策略实验室 — 外部链接，跳到独立页面 `web/lab.html`
- 06 历史数据 — 评测/策略实验的结果保存与检索

**`web/lab.html`**（独立页面，从侧边栏 05 链过去）：
- 页面内子 tab：单版本权重调节·实时重排 / 两版本权重对比

## 现有设计系统

浅色主题，CSS 自定义属性（变量）驱动配色，两个页面各自内联 `<style>`，
**没有共享样式表**（这是已知问题，见下面"已知问题"）。核心变量名：

- `--paper`（页面底色，米白/浅灰）
- `--gold`（强调色，用于分数/重要标签）
- `--indigo`（次强调色，用于链接/交互态）
- `--green`（正向/成功状态，比如"已验证"）
- `--shadow`（卡片阴影）

`index.html` 和 `lab.html` 两边这几个变量的**取值目前一致**（已核对过），
但 `index.html` tab 04 里的"评测工具"面板是后来合并进来的独立页面，为了不
污染主站样式，改成了 `--ev-*` 前缀的一套独立变量挂在 `#panel-4` 作用域下，
所有相关 CSS 选择器都加了 `#panel-4` 前缀限定。**这是刻意的隔离设计，视觉
优化时可以统一 `--ev-*` 和主变量的取值，但不要去掉这层作用域隔离**（否则
会导致 tab04 内部的自定义 class 名跟主站冲突）。

## 已知问题（可以在这轮一起解决）

1. **没有共享 CSS 文件**：`index.html` 和 `lab.html` 各自内联样式，改一处
   配色要两处改。预留了 `web/assets/app.css` 路径但还没抽取。**如果要做视觉
   统一，建议顺手把公共变量/组件样式（卡片、按钮、表格、tab导航）抽取到这个
   共享文件**，两个页面都引用它，具体文本内容/交互逻辑不用动。
2. `lab.html` 独立跳转的方式（点侧边栏 05 会离开当前页）和其它导航项的同页
   切换体验不一致——是不是要改成 iframe 嵌入或者别的方式，由你判断，也可以
   保持现状（当前是有意为之：lab.html 的交互复杂度和主页不同，独立页面更简单）。
3. 侧边导航的样式在两个页面各写了一份（同样的设计、同样的取值），属于上面
   第 1 条"没有共享 CSS"的一部分，抽取共享样式表时一并处理。

## 期望范围

**要做的**：配色/间距/排版/组件视觉一致性、响应式细节、深色模式（如果决定加）、
共享样式表抽取。

**不要做的**：不要改 HTML 结构里跟 JS 逻辑绑定的 id/class（比如 `showTab()`
依赖的 `data-tab`/`#panel-N` 这类），不要改接口调用逻辑，不要删除任何功能性
按钮/表单元素（视觉可以重做，功能入口要保留）。改完希望能直接跑一遍我们已有
的功能回归（每个 tab 能正常切换、每个工具能正常提交请求），不需要新写测试，
人工点一遍就行。

**性能红线（真实踩过的坑，2026-07-26）**：
1. **不要用 `backdrop-filter`（毛玻璃）**，至少不要用在包含任何无限循环动画的
   容器上——header 里有个一直脉动的绿色状态灯（`.dot.ok` 的 `pulse` 动画），
   之前 header 开了 `blur(16px)` 毛玻璃，浏览器被迫每帧重算高斯模糊，整个页面
   背景持续闪烁。已改成不透明纯色修复。同理，新加任何无限动画（loading、脉动、
   跑马灯）前先确认它不在滤镜/毛玻璃容器里。
2. 左侧 fixed 侧边栏上保留 `transform:translateZ(0)` + `contain:layout paint`
   （合成层提升）——去掉会在部分机器上出现滚动闪烁/撕裂。
