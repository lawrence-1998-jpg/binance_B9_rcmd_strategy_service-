2026-07-26，长会话进行中，Lawrence 主动问"用 sonnet 还顺畅吗，需要我给你转 opus
吗"。我说目前顺畅（工作是工程执行为主：写代码/部署/调试/整理文档），真正卡的是
后台任务在跑而非推理能力。他说："后面需要切opus的话，请主动告诉我。"

**Why：** 他不反感升级模型换取更强推理，但不想我自己默默扛着次优表现，也不想他
一直主动问。他把"要不要切"的判断权交给了我，前提是我如实报告。

**How to apply：** 遇到明显需要更强推理的场合（复杂架构决策、容易出错的多步
推理、代码审查这类需要深度判断的任务，或者感觉自己在某个问题上反复兜圈子/
判断力不够用），主动跟他说"这里可能需要切 Opus"，不要因为怕麻烦或不好意思
而不提。日常工程执行（写代码、部署、调试、整理文档）Sonnet 够用，不用主动提。
