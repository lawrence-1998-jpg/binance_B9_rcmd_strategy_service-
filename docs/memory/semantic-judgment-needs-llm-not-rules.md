2026-08-02 B9 冲击力因子根治。判断"标题里这个百分数是不是价格涨跌幅"，
用正则+排除词表做了四轮，每轮都在漏：

    v1 关税/税率 → v2 同比/购金 → v3 税/覆盖/超预期/目标价 →
    v4 opt-in 反转口径 → 仍漏"份额升至67.4%""市占率升破58%"

**Why 规则必然输**：
1. "百分比能表示什么"是**无穷集合**——支持率/市占率/覆盖率/税率/收益率/
   波动率/整合率/持有率/市值占GDP比/门票处理量/协议投票阈值……而"表达价格
   变动"的说法虽是有限集，反过来做 opt-in 也只解决一半：
2. **动词不是判据**。"份额**升**至"、"支持率**降**至"、"渗透率**涨**到"——
   升降涨跌能修饰任何指标。要问的是这个数字**度量什么**，那是语义不是模式。
3. 每加一个词都要重新验证不误伤真实案例（加 `share` 会撞 "Tesla shares
   surge 12%"），维护成本随词表长度超线性增长。
4. 双语系统里每条规则要写两遍，漏一边等于没写（这次中文补完英文没补，
   首屏那两条照样没修好）。

**正确做法**：让**已经在读全文的 LLM** 多输出一个结构化字段回答这个判断。
实测真实网关 12/12，包括"收益率升至5.26%（水平≠变动）"、"跌至10个月低点
（有跌无幅度→不要乱借数字）"这类规则完全无解的边界。存量回填实测
**60% 原本被误判**。

**How to apply**：
1. 出现"第三轮还在补词表"的信号时就该停下来问：这是模式匹配问题还是语义
   问题？语义问题就加 LLM 字段，别再补第四轮。
2. 字段设计：**布尔判断单独拆出来**（便于 QA 断言与人工抽查），附带的量值
   只在布尔为真时有意义；能区分"周期/尺度"的话一并要（日内暴跌 vs 年内累计
   涨幅是两回事）。
3. **prompt 里要写反例和陷阱**，尤其那句"动词在数字旁边不代表它是价格"——
   实测第一版没写这句时，LLM 把收益率水平当成了变动幅度。
4. **规则兜底不能删**：存量数据没有新字段，删了会让它们集体归零，是一次
   无声的全库降级。加 QA 断言把"有字段用字段、无字段用兜底"两条路都钉住。
5. 改 prompt 的代价（enrich 缓存整体失效）要如实预告，但**别把它当成不做
   正确事情的借口**——这次就是先入为主以为 key 不稳定，拖了一轮才做。
