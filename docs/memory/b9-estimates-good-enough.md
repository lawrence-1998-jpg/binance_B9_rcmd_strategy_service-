成本追踪（`usage_tracker.py` 的 token 定价/分桶）、市值/币种标签这类数字，
用户明确说"不用很准确，预估就行，不用花太多力气"。

**Why**: 这些是辅助决策用的参考数字，不是直接影响推荐结果排序的核心字段
（核心打分见 [[b9-dedup-gap]] 里提到的 scoring.py 公式），过度投入精度打磨
性价比低。

**How to apply**: 遇到"要不要再加一层校验/再核对一次定价表/再提高匹配精确度"
这类岔路时，默认选够用就好的那一档，不用主动加码去做更精确的版本；已经做完
的（比如市值标签 92.5% 匹配率、这次的 by_model 成本分桶）不需要回头再优化，
到此为止。真正需要抠精确度的是直接影响事件去重/排序的阈值（这类不在本条覆盖
范围内，见 [[b9-dedup-gap]]）。
