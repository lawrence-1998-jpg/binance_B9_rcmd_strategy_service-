2026-07-26 深夜，Lawrence 在连续第五次亲自发现本该我自己发现的问题后爆发
（原话大意）："为什么你还在做错这些事？为什么不每次都在你的网站上测试你的
功能？为什么需要我来当 QA？请完成**整个流程**——不要做了第一步就忘了第二步。
如果你不把功能放上界面，数据只是躺在表里，那就是浪费钱和时间。把这个写进
你的长期记忆，帮我省时间、省精力、省钱。"

**五次真实事故**（全部由用户发现，我本可以自己发现）：
1. "导航栏"做成顶部tab就标完成，没给用户看过成品
2. 策略实验室子tab需求整条丢失
3. 给后端补鉴权，前端没带token，用户截图 Unauthorized
4. backdrop-filter 闪烁，用户报"背景一直在闪"
5. 真实相关性算法在服务端上线了，用户界面上还挂着假的二元 Rel 和"尚未上线"
   的提示——我甚至书面承诺过"届时一并处理不用你提醒"，然后没做

**共性根因**：我在自己改动的那一层验证（curl 200 / DB 有数据 / 代码逻辑对），
从不站到用户打开网站的那个位置走最后一步。"后端做完"被当成了"做完"。

**How to apply（铁律，适用于所有项目）**：
1. **Done 的定义 = 在用户实际触达的界面上、以用户的操作路径亲自走通并看到
   正确结果**。curl 200、落表成功、单测通过都只是中间状态，不是 Done。
2. **任何触及 UI 或 UI 所调接口的部署，部署完立刻在浏览器里过一遍全站主要
   路径**（每个导航项点开、改动的功能按用户流程操作一次、看 console 报错）。
   这一步不问值不值得，无条件做。
3. **每个花钱产出的数据资产必须有消费方**：新增字段/能力时，同一批工作里
   接好它的用户界面或明确记录"刻意暂不展示+原因"。定期跑孤儿审计
   （grep 字段名在前端的引用数，0 引用=红灯）——2026-07-26 审计实测抓出 6 个
   零消费字段，含用户明确点名要过的市值标签。
4. **书面承诺过的后续（"届时会一并处理"）必须立刻落成 TODO 条目**，不许留在
   文档段落里等自己记起来——文档不会提醒人，TODO 会。
5. 交付说明里附**用户视角的证据**（截图/界面上的实际值），不是接口返回值。
6. **编码完成后必须进入全流程 QA 阶段，拿到 no-bug 测试报告才算交付、才能给
   用户看**（2026-07-26 追加的规矩）。做法：把 QA 写成**可重复执行的脚本**
   （B9 是 `scripts/qa_suite.py`，67 条用例：服务/鉴权/接口/写入链路/数据不变量/
   交互工具），跑到全绿 + 浏览器人工路径全通 + 控制台零错误，产出报告文档。
   脚本只断言**不变量**（鉴权必须拦住、指纹不能重复……）以便无脑重跑；写库用例
   自清理；花钱的用例单独标注可跳过。**首次执行就抓到一个真实扣费 bug**
   （空请求静默变成付费运行），证明这道门禁值得。

7. **界面看起来正常 ≠ 数据是对的**（2026-07-29 追加，第六次事故）。那次我按
   上面全部流程做了：浏览器逐 tab 走过、QA 98/98 全绿、报了"达到交付标准"——
   而库里正躺着一条 2024 年的新闻顶着 2026 年的日期在前端展示。界面渲染得
   完美，**说谎的是数据本身**。所以视觉验证之外还要问："这些字段的值，有没有
   可能是编出来的？"并把答案写成 QA 里的**内容正确性不变量**（不是接口形状
   不变量）。详见 [[never-default-missing-data]]。
