B9 推荐策略服务 · 排序因子体系

七个基础因子 + 两个加分项
怎么把「重要」变成一个可调的数

本次改造把排序从「五因子加权」升级为两段式模型：先算一个跨天可比的基础分，再叠加一层反映当下市场氛围的倍率。新增 广度、冲击力 两个基础因子和 情绪同向、反转信号 两个加分项——这份材料讲清楚它们各自定义什么、为什么这么定、以及从真实数据里读出的几条结论。

两道红框闸是本轮新增/收紧的：前者拦「时间不可信」，后者拦「时间太旧」。两个绿框是本次改造的核心——打分从五因子扩到七因子，并把「当下氛围」从基础分里剥离出来做外层倍率。

为什么把加成做成「查询时的外层倍率」而不是写进分数

加成依赖 mood_score（大盘情绪），这个值每天都在变。如果把它算进 importance_score 写库，昨天算出的分和今天算出的分就不可比了——而这个字段是策略实验室、去重、历史分析共同依赖的口径。

拆成两段之后：基础分是「这条新闻本身有多重要」，跨天可比、可复现；加成是「在今天这个市场环境下它该被抬多高」，随时可以把系数调 0 退回纯基础排序——这也是验证加成真实贡献的 A/B 对照方式。

02

两段式打分模型

基础分BaseScore = 0.26·M + 0.16·B + 0.16·T + 0.14·I + 0.10·H + 0.10·A + 0.08·Q
最终分FinalScore = BaseScore × ( 1 + 同向加成 + 反转加成 )　// 合计封顶 +50%

高亮部分为本次新增。七个基础因子权重合计 100%，加分项不参与归一化。

03

四个新增项的具体定义

每一项都说明三件事：算什么、为什么这么算、以及刻意没做什么——最后一项往往比前两项更重要，它防止同一个信号被重复计分。

B 广度Breadth 新增 16%
定义：这件事波及多大范围。刻意与「有多重要」分开——一家公司的重大丑闻再轰动，波及范围仍然只是它自己。
cross_market跨市场：同时波及股市与加密，或多国大盘（美联储决议、全球关税、战争扰动油路）1.00 market_index单一市场大盘级（日经暴跌、KOSPI 熔断、纳指创新高）0.80 sector板块级，不是整个大盘（AI 芯片股集体下跌、DeFi 监管）0.60 multi_asset明确波及 2–5 个标的，但不构成板块0.35 single_asset只关乎一家公司/一个币种0.15
为什么用五档枚举而不是让模型直接打 0–1 分：枚举的判据能写清楚、能复核、能对齐；让模型自由打连续分，实测只会得到一堆 0.7。分档由 LLM 判定，映射成分值由代码固定，改档位定义不用改模型。
I 冲击力Punch 新增 14%
定义：0.65 × 数值幅度 + 0.35 × 权威共振。捕捉「这条读起来有多冲」——跌 18% 和跌 0.3% 在其它因子上可能完全一样，但用户感受天差地别。纯计算，零 LLM 调用。
幅度 ≥15%或命中「熔断/崩盘/暴跌/涨停」等极端词1.00 8–15%0.75 4–8%0.55 2–4%0.35 无数字没抽到任何涨跌幅0.10

权威共振数的是 authority≥4 的独立机构家数（3 家以上给满分）。它和热度因子的区别：热度数的是所有信源、会被社交互动稀释；共振只数一线财经机构——「三家一线媒体同时报」本身就是「这是件大事」的强信号。

刻意没做的：原始需求里还有一项「对社会经济产生重大影响」。对照后发现它已经被 M（影响面） 和 B（广度） 覆盖了两遍，再单列就是三重计分——同一个信号进三次，权重会被悄悄放大到设计意图之外。
两个真实的取数陷阱（都已修）：①「征收 100% 二级关税」里的百分数是税率不是波动，会把冲击力顶满——已加语境词表识别（关税/利率/持股/概率等），数字前后都查；②跨轮归并时正文刻意不更新、幅度却按新正文算，导致「KOSPI 跌超 8%」旁边标「幅度 80%」——已改为打分与入库共用同一份正文。
☾ 情绪同向加成Align 新增 上限 +25%
定义：k × |大盘情绪| × |事件情绪|，仅当两者方向一致时生效，反向或大盘中性时为 0。

解决的是「内容很平、没有感觉」——大盘集体悲观时，负面消息本就该更靠前，这是用户此刻真正关心的东西。加成有界（不是无限放大），且大盘接近中性时自动失效。

为什么不做减成：只加不减，意味着「大悲观时段里少数逆势乐观的消息」不会被排序打压到看不见——用户仍然能看到「情况没那么糟」的信号，只是不会被推到最前面。
⚡ 反转信号加成Reversal 新增 上限 +20%
定义：同样是 k × |大盘情绪| × |事件情绪|，但仅当方向相反、且事件为 S/A 档时生效。与同向加成互斥，一条事件最多命中一个。

这是整套模型里最重要的一个设计决策，它专门用来对冲同向加成的副作用。

不加它会发生什么：大盘暴跌 → 同向加成集体抬高负面内容 → 首屏全是坏消息 → 而此时一条「美联储可能提前降息」的反转信号恰恰被压到看不见。金融产品里放大情绪 = 放大追涨杀跌；真正伤害用户的不是内容平淡，是该看到反转时看不到。
S/A 档硬约束是它成立的前提：没有这个约束，大盘单边时所有反向的噪音都会被扶上来，反而更乱。只有「重大 且 与大盘反向」才是真信号——档位低的反向内容拿不到这个加成。

05

从真实数据里读出的五条结论

一 · 新因子确实在区分内容，不是白算的

把首屏 Top20 的因子均值和全库均值对比：广度 0.705 vs 0.416，冲击力 0.693 vs 0.250。冲击力的首屏均值接近全库的 2.8 倍——说明「跌 X%、多家权威共振」这类特征确实被排上去了。如果这两个数接近，就说明因子只增加了计算量、没有区分力。

二 · 排序改造的效果，主要体现在非加密内容的可见度上

对照改造前的真实排序快照：非加密内容在首屏的占比 45% → 55%，S/A 档占比 80% → 90%，Top20 换手率 45%。换手率本身不是「变好」的证据（它只说明排序确实变了），方向性的证据是前两项。

三 · 首屏是一条连贯叙事，不是十条互不相干的快讯

当前 Top8 读下来是：芯片股抛售 → 拖累亚洲大盘 → 韩国日本相继熔断 → 背后叠加霍尔木兹地缘风险。用户翻到第 8 条还能感觉到「这些事互相有关系」——这才是热度感的核心，不是单条新闻多耸动，而是整体氛围有没有拧成一股绳。情绪横幅的 −0.439 与首屏内容方向完全一致，没有出现「横幅说悲观、内容却平静」的割裂。

四 · 热度因子会给出反直觉的低分，这是设计而不是缺陷

首屏多条重大事件的 H（热度）只有 0.05–0.30。原因是热度只看「信源数 + 社交互动」，即已经被多少人关注过，而不是应该有多重要。刚发生的重大事件天然还没积累关注度，两者本该有落差。

这个落差不是 bug，但会被用户读成 bug（「这么大的事热度才 0.1？」）。建议在产品文案上解释清楚，而不是改公式去迎合直觉——一旦让热度去承担「重要性」的表达，它和 M/B 就重复了。

五 · 同一件大事会被拆成多张卡片，这是去重粒度的固有张力

实测案例：「芯片股抛售」这条主线，FT 的单信源版本落在 B 档 0.474，而 9 家信源合并的版本落在 A 档 0.680。两条讲的是同一件事，FT 那条因为语义相似度没跨过合并阈值（0.82，在 855 条真实事件上标定过），没拿到「多源共振」的加成。

结论是主线本身排得靠前，只是某一家媒体的具体卡片不一定是最靠前的那张——不是分类错误。要消除它就得下调合并阈值，代价是误合并不同事件，那个代价更大。
