# 随手拾

**随手复制的信息，贴进来就被整理成一张卡片 —— 收着、找得到、随时复制出去用。全部存在你自己的设备上。**

聊天里的会议时间、名片、报价、链接、报错、一段想法、一张截图……粘贴即收下。
本地当场整理：认出时间、地点、电话、邮箱、金额、链接、验证码、截止日期、要做的事，
聊天里是谁说的（「王总：…」），按类型配好「拿去问 AI 的那一句」。

## 可选：接上你自己的 Claude

设置 → 「Claude 整理」→ 填你自己的 API Key（在 console.anthropic.com 创建，按用量记在你自己的账户上）。
开了之后：

- 贴进来的每一条交给 Claude 读懂重写（标题、一句话要点、字段、待办、下一步问 AI 的那句）
- 截图也能收 —— Claude 先读出图里的字
- 搜索框里直接提问：「Lily 的电话？」「这周有哪些会？」，用你收的卡片回答并标出处

不填也完全能用。随时可以「关掉并删除 Key」。

## 怎么用

| 想做的 | 怎么做 |
|---|---|
| 收 | 长按收件框粘贴 ／ 电脑上在页面任何地方 ⌘V ／ 打字后点「收下」／ 安卓装成 App 后从别的 App「分享」进来 |
| 收截图 | 点「截图」从相册挑 ／ 直接粘贴一张图 ／ 电脑上拖进来 |
| 复制一格 | 点字段那一行（或卡片上的字段小条）—— 只复制那个值 |
| 复制整张 | 右上角复制按钮 = 整理版；展开后「复制整理版 / 复制给 AI / 复制原文」 |
| 拿去问 AI | 「复制给 AI」= 一句指令 + 整理好的信息 + 原文，贴进哪家 AI 都能直接用；截图卡能「复制图片」 |
| 换个问法 | 展开的卡上「换个问法」：起草回复、提炼要点、翻译成英文……点一下连同这条信息一起复制；设置 →「我的问法」存你自己常用的那句 |
| 放到别处 | 有时间的卡「加到日历」（.ics，手机点开就弹「添加到日历」，提前 15 分钟提醒）；有电话 / 邮箱的「存到通讯录」（.vcf） |
| 合成一段 | 「选择」→ 勾几张 → 复制整理版 ／ 复制给 AI |
| 找 | 按类型筛（日程、联系人、待办…）／ 🔍 搜标题、原文、字段 |
| 反悔 | 删了能撤销；同一段贴两次不会收两条 |
| 换设备 | 设置 → 导出备份（一个 JSON 文件，连「我的问法」一起）→ 那边导入备份 |

## 隐私

- 没开 Claude：**一个请求都不出这台设备**，连 Claude 的 SDK 都不下载。
- 开了 Claude：收下的内容、截图、提问从这台设备**直接**发给 `api.anthropic.com`，不经过任何别的服务器；
  Key 只存在这台设备上，只放在发给 Anthropic 的请求头里，不进卡片、不进备份文件。
  请求开着服务端 fallback（`fallbacks: "default"`）：主力模型偶尔不接某条时，Anthropic 自动换一个模型接着整理。
- 页面没有埋点、没有外链字体。`test/private.mjs` 把上面每一条都变成了会失败的检查。

## 目录

```
src/

  examples.ts      库还空着时的三张示例卡（没开 Claude 时按本地整理的样子显示）
  lib/card.ts      纯逻辑：本地整理、给 Claude 的指令（文字 / 截图）、核 Claude 的回复、复制出去的样子
  lib/ai.ts        可选的 Claude：Key 存取、整理 / 提问 / 测 Key、出错归类（SDK 按需加载）
  lib/ask.ts       问一问：挑哪些卡塞给 Claude、回答里的 [编号] 变回卡片
  lib/send.ts      放到别处：读「周五上午 10 点」这种时间、生成日历文件（.ics）和联系人文件（.vcf）
  lib/image.ts     截图压成一份存得下的图；复制图片时转 PNG

  lib/copy.ts      写剪贴板（文字带 execCommand 兜底；图片）
  lib/update.ts    GitHub Pages 装成 App 时，新版本怎么到手上
  styles/app.css   全部样式；颜色只在 :root 里定义
test/              见 test/README.md
```

## 改动时别踩的线

- **复制必须在点击事件里同步发起。** iOS 只认用户手势里发起的剪贴板写入（图片也一样）。
- **Claude 的回复不可全信**：一律过 `fromAi()`，缺的补、假的（「无」「未提及」）丢。
- **没填 Key 就不许有任何外部请求。** 不许从循环或定时器里调 Claude：只在收下一条、她点「重新整理」、她提问时调；
  Key 用不了就停手（不每收一条都撞一次），等她去设置里换。
- **先改内存再落盘**：`store.ts` 里紧挨着的两笔改动按顺序落到 IndexedDB。
- 能点的不小于 44×44，输入框字号不小于 16px。`look.mjs` 盯着。
