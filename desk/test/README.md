# 随手拾的行为测试

    cd desk
    npm test                  # 跑全套（会自己先构建、起服务）
    npm test -- unit flow     # 只跑指定的几条

| 套件 | 管什么 |
|---|---|
| `unit` | 纯逻辑：本地整理（电话、金额、时间、地点、截止、待办、清单、类型、配好的那句问法）、给 Claude 的指令（文字 / 截图）、核 Claude 的回复、复制出去的样子、问一问挑卡和出处、备份导出导入合并 |
| `flow` | 本地版（默认，没填 Key）：收 → 本地整理 → 各种复制 → 待办 → 筛选搜索 → 多选 → 删除撤销 → 置顶改标题 → 刷新还在 → 清单 → 截图（没有 AI 也收、能复制图片）→ 分享进来 → 导出 / 换设备导入 → 老版本数据搬家。**每一步复制都读真的剪贴板，每一步存储都读真的 IndexedDB** |
| `ai` | 填了自己的 Key（`mock-anthropic.mjs` 假接口）：填错 / 测不过 / 测过 → Claude 整理（核对真正发出去的请求：模型、结构化输出、fallback、Key 放在哪）→ 读截图 → 忙 / 不接 / 断网 / Key 失效时怎么退 → 重新整理 → 问一问 → 关掉之后不再发请求 |
| `offline` | 真断网：本地版照样能收、能认、能复制、能导出；开着 Claude 时断网不卡住，有网了补上 |
| `look` | 手机 / 小屏 / 电脑 × 浅色 / 深色，空着 / 收了几条 / 设置 / 截图卡 / 问答 / 多选：对比度、44px、不出界、不裁字 |
| `private` | 没开 Claude 一个请求都不出网（连 SDK 都不下载）；开了只到 api.anthropic.com、Key 只在请求头里、不进卡片和备份；关掉删干净；打包后的代码里没有埋点 |
| `single` | 仓库里那份离线单文件版：charset 在头 1024 字节、双击能开、能收能复制、刷新还在；填了 Key 在 file:// 下也能叫 Claude |
| `swupdate` | GitHub Pages 那一版：新版本打开一次就到手上 |

`mock-anthropic.mjs` 用 Playwright 的 route 接住发往 `api.anthropic.com` 的请求，
按 Messages API 的形状回（非流式 JSON / 流式 SSE，带 CORS 头）。`api.fail = 'rate_limited'` 之类
可以让它按那种方式失败；`api.calls` 记着每一个请求，测试拿来核对。测试从来不碰真网络、不需要真 Key。

注意：Playwright 的 route 会绕过 `setOffline` 的断网模拟。要测真的「连不上」，那一段就别装假接口。

## 为什么这些东西在仓库里

以前它们只存在于一次会话的临时目录。也就是说每一次「全绿」除了那次会话
**谁都复现不了** —— 包括仓库的主人和下一个来干活的人。
一套没人能重跑的测试，等于一句没人能核对的承诺。

## 几条自己踩出来的规矩

**`✓0` 不叫通过，叫没说话。** 探针类脚本只打印测量值、一条断言都不出，
而它们印出来的 `✓0` 跟真绿长得一模一样，被算进过「全绿 N 条」。
现在单独标「探针，没有断言」，并且不计入总数。

**脚本崩了和断言失败必须分开。** 早先那个一行 `for` 循环只数 ✓/✗ 的行数，
脚本中途崩掉照样报「✗0」。`run-all.sh` 认退出码，崩了单独标「💥」并打尾部日志。

**被测的 dist 必须是干净的。** `swupdate` 为了测升级路径会把 dist
换成别的版本。它一旦中途崩了，后面每一条套件测的都是错东西 —— 曾经因此
五个套件一起变红，而它们单独跑全是绿的，差一点就去改了没坏的代码。
现在每跑完一条就比对一次，动过就还原，还原不成直接停。

**每条新检查都要先证明它会红。** 加一条检查之后，把对应的代码改坏一次，
确认它真的报警，再改回来。不这么做的话，写出一条永远不会红的检查太容易了 ——
比如曾经有一条私人照片扫描，只认 `jpg/heic`，而仓库里一张都没有，
它扫了 0 个文件报了个绿。

毒化的时候注意：这个项目开了 `noUnusedLocals`，很多「改坏一次」的写法会让
**构建直接挂掉**，测试根本没跑，而只数 `✗` 行的验证脚本会打印一片空白，
看起来像「没问题」。要么挑一个仍然能编译的改法（把比较符反过来、把常数
改掉），要么让验证脚本在拿不到结果时自己喊出来。

**动过 UI 就拍一张看看。** 断言验的是「有没有按我写的规则跑」，不是
「跑出来的东西是不是人话」。后者只能看。`look.mjs` 每次都会把截图存进 `test/shots/`。

## 环境

- `playwright` 的版本在 `package.json` 里**钉死**（不带 `^`）：它必须跟机器上
  装的浏览器对上，浮动版本会直接起不来浏览器。
- `DESK_URL=...` 可以指着一个已经跑起来的地址，跳过自动构建和起服务。
- `DESK_PORT=8766` 换端口。
- 截图落在 `test/shots/`（不进版本库；CI 里测试挂了会作为 artifact 传上来）。
